# Locations

![The Locations page](/screenshots/locations.png)

Locations represent the physical places where your books live — a shelf, a room, a branch, or anything else that makes sense for your collection.

## Managing locations

The **Locations** page lists every location as its own card, with its **description** and the **total number of books** currently stored there.

![The Add location dialog](/screenshots/location-dialog.png)

- Click **Add** to create a new location, giving it a name and description.
- Use ✏️ to edit a location, or 🗑️ to delete it (with confirmation).
- Expand a location's card to see the **books stored there**.

## Default location

Click the ⭐ next to any location to mark it **Default** — only one location can hold that badge at a time.

![The Locations page, with one location marked as Default](/screenshots/locations-default.png)

Your default location is pre-selected whenever you [add a book manually](./adding-books#add-manually), so a physical copy is created there automatically unless you pick a different one (or clear the field to add the book without any stock). It's handy if most new arrivals end up in the same place.

## Using locations

Once created, a location becomes available wherever you assign a physical copy to a place:

- Selecting a location while [adding a book by ISBN or manually](./adding-books).
- Choosing a location when [adding or editing a stock copy](./book-details) on a book's page.
- Automatically, one per custom shelf, when [importing from Goodreads](./importing-books#importing-from-goodreads).

This makes it easy to answer "where is this book?" or "what's on shelf B?" at a glance.
